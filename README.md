TaskMastR is a full-stack web platform developed to connect clients with local service providers in the collaborative economy. 
Built with the MERN stack, it offers a secure, transparent, and efficient environment for posting tasks, direct bidding, and managing local services

Tech Stack 

Frontend: React, Tailwind CSS  
Backend: Node.js, Express.js  
Database: MongoDB with Mongoose  
Security & Auth: JSON Web Tokens (JWT), bcrypt.

Key Features 

Multi-Role System: Dedicated interfaces and capabilities for Clients (Beneficiaries), Providers (Professionals), and Administrators.  
Task Management: Clients can easily post detailed service requests specifying the category, estimated budget, and location.  
Direct Bidding: Providers can browse open tasks in their feed and submit custom offers (proposed price and a personalized message).  
Real-Time Communication: Integrated chat module that activates once an offer is accepted, ensuring fast and secure communication.  
Reviews & Ratings: A transparent feedback system where clients can rate (1-5 stars) and review providers upon task completion.  
Admin Dashboard: Centralized control panel for moderating users and active listings to maintain platform safety.
